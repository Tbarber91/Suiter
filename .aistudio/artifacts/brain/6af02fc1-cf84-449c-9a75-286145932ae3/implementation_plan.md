# Implementation Plan: Room Staging & Building Plan CAD Studio

Build an architectural room staging and interactive 2D/3D building plan CAD studio, powered by a multi-model AI engine (Grok, ChatGPT, Gemini), coupled with SALIS land management zoning overlays, automated municipal regulatory compliance checking, online paperwork vault (contracts & certificates), and enterprise-grade security enclave fencing.

---

## User Review Required

> [!IMPORTANT]
> Please review and confirm the key architectural decisions below before implementation proceeds:

1. **Multi-Model Engine (Grok, ChatGPT, Gemini)**: 
   - Gemini operates natively server-side via `@google/genai`.
   - Grok (xAI) and ChatGPT (OpenAI) endpoints will be structured via secure server-side API proxy routes (`/api/ai/grok`, `/api/ai/chatgpt`, `/api/ai/gemini`) with real fallback simulation and customizable API credentials.
2. **CAD Plan Drawing & Virtual Room Staging**:
   - Interactive SVG/Canvas architectural plan generator with room sizing, wall thickness, door/window placement, layer management, and live dimensioning.
   - Dual-view Room Staging studio inspired by the provided reference image (empty vs. furnished split slider, style presets: *Transitional, Contemporary, Modern Farmhouse, Minimalist, Coastal*, and custom furniture request generator).
3. **SALIS Land Management & Spatial Boundary Overlays**:
   - Real-time parcel boundary overlays on the map, zoning classifications, soil percolation ratings, flood/bushfire risk ratings, and title certificates.
4. **Security & Compliance Fencing**:
   - Contained end-to-end encryption simulation, Secure Enclave isolation, anti-SQL injection sanitization, automated session gates that lock all access points immediately upon exiting or stopping work, and license audit display (Apache 2.0, MIT, Lottie, Uber, Airbnb open-source compliance).

## Proposed Changes

### 1. Multi-Model AI Engine & Security Fencing (`/lib/ai-engine.ts`, `/app/api/ai/*`)
- Create unified AI engine interface supporting **Grok (xAI)**, **ChatGPT (GPT-4o)**, and **Gemini 2.5/Flash**.
- Implement architectural prompt templates:
  - Building plan CAD generation (JSON vector specs: walls, doors, windows, measurements).
  - Virtual staging furniture recommendations & style analysis.
  - Land zoning code interpretation and council requirement analysis.
- Create automated session gatekeeper that seals active keys and terminates session state when closing or idling.

### 2. Room Staging Studio Component (`/components/RoomStagingStudioModal.tsx`)
- Implement split-screen interactive before/after slider (Empty to Furnished) mirroring the reference design.
- Style carousel: Transitional, Contemporary, Modern Farmhouse, Scandinavian, Mid-Century Modern, Coastal.
- Furniture & decor request builder with instant visual staging preview, material palette selector, and high-res export.
- Integrated "Use This Template" workflow to pass staged spaces directly to building contractors or leasing listings.

### 3. Interactive Building Plan CAD Studio (`/components/BuildingPlanCADModal.tsx`)
- Vector blueprint canvas with grid snapping, scale ruler (1:50, 1:100), metric/imperial toggles.
- Architectural toolset: Wall pen, room partitions, door swings, double-hung windows, structural columns, electrical & plumbing symbols.
- Instant AI Plan Generation button: Prompts Grok/ChatGPT/Gemini to generate complete multi-room floor plans matching site zoning setbacks.
- One-click DXF/SVG/PDF export with architectural title blocks and engineering stamp placeholders.

### 4. SALIS Land Management & Zoning Dashboard (`/components/LandManagementDashboard.tsx`)
- Land parcel registry with Lot/Section/Plan search, boundary coordinates, and area calculation.
- Integrated Map boundary overlay (GeoJSON parcel polygons with color-coded zoning: Residential R2/R3, Commercial B1/B2, Industrial, Agricultural).
- Soil report analyzer: Soil classifications (Clay, Loam, Sandy Loam, Bedrock depth), bearing capacity (kPa), drainage index, and foundation recommendations.

### 5. Regulatory Compliance & Municipal Building Code Checker (`/components/RegulatoryComplianceModal.tsx`)
- Automated compliance evaluation engine:
  - Compares planned floor area ratio (FAR), site coverage %, building height, and boundary setbacks against local council Local Environmental Plans (LEP) / Development Control Plans (DCP).
  - Pass / Warning / Fail visual indicators with citation of relevant standards (NCC / BCA, AS/NZS codes, OSHA/SafeWork regulations).
  - Remediation suggestions generated by Grok/Gemini for non-compliant setbacks or height limits.

### 6. Online Paperwork & Legal Contracts Vault (`/components/PaperworkContractsVaultModal.tsx`)
- Template & contract management for building agreements, land title transfers, surveyor certificates, development approvals (DA), and occupancy permits.
- Digital signature workflow with cryptographic timestamping and SHA-256 integrity hashing.
- Standard legal clauses covering Apache 2.0, MIT licensing, intellectual property rights, and copyright protections.

### 7. Main Navigation & Page Integration (`/app/page.tsx`, `/components/Header.tsx`)
- Connect top toolbar and hero action triggers to open:
  - **Room Staging Studio**
  - **Building Plan CAD Studio**
  - **SALIS Land & Zoning Hub**
  - **Compliance Checker**
  - **Contracts & Certificates Vault**
- Embed parcel zoning boundary layers seamlessly into the existing `/components/Map.tsx`.
